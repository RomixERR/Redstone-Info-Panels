## Redstone Info Panels

Redstone Info Panels adds configurable information displays and wireless redstone communication to Minecraft.

Create a **Redstone Info Panel** to display custom text based on the current redstone signal strength. Configure individual messages, text colors, sizes, and panel colors for all 16 signal levels from 0 to 15.

The mod also includes a **Wireless Redstone Receiver**. Unlike many similar wireless redstone blocks, this receiver supports the full **analog redstone signal range from 0 to 15**, allowing it to transmit signal strength—not just an on/off state. This makes it useful for wireless control of lamps, machines, circuits, and other devices that require variable signal levels.

Use the **Redstone Linker** to connect panels and receivers to redstone signal sources.

### Features

- Configurable redstone information panels
- Custom text for all 16 redstone signal strengths
- Support for text size, text color, and panel face color
- Wireless redstone receiver with full analog signal support
- Redstone signal transmission from 0 to 15
- Link panels and receivers to signal sources using the Linker
- Blocks can be mined by hand or with any tool
- All block settings are preserved when the block is broken
- Placing the block again restores its previous configuration
- Reset a configured block by placing its item into a crafting grid
- Works with both configured and unconfigured block items when resetting settings
- Compatible with Minecraft 1.19.2 and Forge 43.5.0
